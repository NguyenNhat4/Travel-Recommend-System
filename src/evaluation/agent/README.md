# Đánh giá Itinerary Agent qua Streamlit

Code demo và bộ đánh giá nằm ở thư mục này (`streamlit_app.py`). Trước khi sửa hoặc tune, đọc
[working context](../../../docs/agent/working-context.md), rồi chỉ mở nhánh Evaluation trong bảng chọn
context. Tài liệu đầy đủ nằm ở [docs/agent/](../../../docs/agent/README.md): cách chạy, trace LangGraph,
response/lỗi và cách chấm.
